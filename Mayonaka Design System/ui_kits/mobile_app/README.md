# Midnight FM — Mobile

Two phone screens side-by-side: a Browse screen (greeting + on-air strip + mixtape grid) and a Now-Playing screen (album art with sun+grid motif, transport, like, queue).

- `index.html` — entry, renders two phone frames
- `Screens.jsx` — `PhoneFrame`, `StatusBar`, `BrowseScreen`, `PlayerScreen`

Icons via Lucide CDN.
