# Card

Default content surface. Translucent glass-1 background, light border, soft hover lift. Compose freely — RIFT cards are not opinionated about their inner layout.

```jsx
<Card>
  <h3 style={{ fontFamily: "var(--font-display)" }}>Signal stream</h3>
  <p style={{ color: "var(--ink-2)" }}>Packets ingested every 200ms.</p>
</Card>
```
