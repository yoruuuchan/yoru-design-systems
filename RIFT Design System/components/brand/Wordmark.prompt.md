# Wordmark

The RIFT wordmark — Chakra Petch in bold, with the chromatic glitch effect baked in. Use one per page (header, splash, or hero) and let the ambient `data-glitch` / `data-accent` on the page wrapper drive the intensity.

```jsx
<Wordmark />
<Wordmark text="RIFT//2" size="var(--text-5xl)" />
```

For arbitrary glitch text (not the brand mark) use `<Glitch>` instead.
