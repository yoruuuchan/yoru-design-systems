# Badge

Pill-shaped status label with a glowing leading dot. The dot inherits `currentColor`, so the variant drives both at once.

```jsx
<Badge variant="ok">CONNECTED</Badge>
<Badge variant="warn">DEGRADED</Badge>
<Badge variant="bad">OFFLINE</Badge>
<Badge>v2.4.1 — STABLE</Badge>
```

Keep labels short and uppercase. Use sparingly — one or two per view, not a wall of badges.
