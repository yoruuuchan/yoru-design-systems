# UI kit · 公众号排版

和小红书图文台读的是同一个 `content.js`。同样的 block，不同的版式规则 —— 不是把卡片缩小贴进来。

**与卡片版的差异**

| | 小红书卡片 | 公众号文章 |
| --- | --- | --- |
| 列宽 | 1050 px | 677 px（手机 375） |
| 正文 | 40 px / 1.75 | 16 px / 1.85 |
| 分页 | 自动切成 N 页 | 连续滚动，不分页 |
| 标题层级 | 每页一个 H1 | 一个 H1 + 多个 H2 |
| 图片 | 定宽定比，最多一张 | 可连续多张 |
| 结尾 | 独立结尾卡 | 文末署名区 |

**「复制到公众号」** 把渲染结果里的计算样式冻结成行内 `style`，去掉 class 与外链 CSS，写进剪贴板。粘进公众号编辑器即可。

已知限制，都写在这里，不要在别处再猜一遍：

- 公众号不加载外部字体。中文会落到 PingFang SC / 微软雅黑，等宽会落到系统等宽。版式按这个前提设计过，掉字体不会散。
- `display:flex` 与 `gap` 在部分安卓客户端表现不稳。导出后请在手机上过一遍长表格与步骤列表。
- 代码块导出为深色 `<pre>`，公众号不会做语法高亮，本系统本来也不做。
- 图片需要在公众号后台重新上传，导出的 HTML 只保留占位与图注。
