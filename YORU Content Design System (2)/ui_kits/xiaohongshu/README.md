# UI kit · 小红书图文台

一条线性内容流 → 自动分页 → N 张 1242×1656 卡片。这是 YORU 小红书内容的生产界面。

| 文件 | 作用 |
| --- | --- |
| `content.js` | 一篇真实推文，写成 `blocks[]` 数组。换内容只改这个文件。 |
| `blocks.jsx` | 把 block 类型映射到 YORU 组件。唯一解释 block 语义的地方。 |
| `paginate.jsx` | `usePagination()` — 离屏测量每个 block 的真实高度，再贪心装页；落单的标题自动推到下一页。 |
| `workbench.jsx` | 工具条（变体 / 尺寸 / 缩放）+ 页面画布。 |

**分页规则**：内容高度 = 画布高 − 上下边距 ×2，块间距取 `--flow-block`。装不下就开新页，不切分单个 block —— 一段代码、一张表、一个步骤列表永远完整地待在一页里。要把长列表拆开时，用 `StepList start={n}` 手动续号。

**导出**：工具条的「导出图片」走浏览器打印，每页一张。缩放只影响预览，导出永远是 @1x 原始像素。

**换变体**：工具条切换即可，四个变体共用同一套分页结果 —— 只有强调色、标签形状、行高和装饰会变。
