Cite what you read. On Xiaohongshu URLs are not clickable — print them anyway, readers retype them.

```jsx
<ReferenceList items={[{title:"Claude Code 文档", source:"Anthropic", url:"docs.anthropic.com/claude-code"}]} />
```

`title` 默认「参考」。每条 `source` 写出处名，`url` 只在公众号与网页里可点，小红书出图时会退化成纯文字——所以链接要短到能被手抄。
卡片组的最后一页、文章的末尾各放一处，正文里不要插。
