着重号 — Chinese emphasis dots set under a phrase; the system's primary emphasis mark.

```jsx
<Heading level={1}>把一条提示词拆成<Emphasis>三层结构</Emphasis></Heading>
```

Use it on the two or three characters that carry the sentence, not a whole clause — dots under a full line read as noise. This is the reason the system has no underline, no bold-colour body text and no highlight-by-default.

For Latin runs, code identifiers or long phrases use `<Marker>` instead: emphasis dots collide with lowercase descenders.
