# Divider

Three rules in one component.

```jsx
<Divider />                       {/* dashed — between paragraphs */}
<Divider variant="solid" />       {/* ink rule — between sections */}
<Divider variant="block" />       {/* ░▒▓ ornamental run */}
<Divider variant="block" label="archive" />  {/* ░▒▓ archive ▓▒░ */}
```
