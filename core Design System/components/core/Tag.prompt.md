# Tag

Pixel-mono 12px label with a 1px ink border. Used heavily in archive views and footnotes.

```jsx
<Tag variant="pool">poolcore</Tag>
<Tag variant="dream" bracketed>halo</Tag>
<Tag variant="sodium">sodium-lamp</Tag>
<Tag variant="ink">drained</Tag>
```

`bracketed` wraps the text in literal `[ … ]` — preferred in archive metadata lines.
