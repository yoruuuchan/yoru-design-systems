# Card

Bordered paper surface — 1px ink border, offset drop shadow, never rounded.

```jsx
<Card>
  <p>the pool was drained two summers ago…</p>
</Card>

<Card variant="pool">…</Card>
<Card variant="dream">…</Card>
<Card variant="sunk">…</Card>   {/* sunken/inset — for "log" content */}
<Card variant="ghost">…</Card>  {/* dashed border, no shadow */}
```
