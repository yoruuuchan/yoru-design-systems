# Marquee

Scrolling rainbow text. The Y2K "welcome" / "now playing" / "construction zone" UI element. One per page max.

```jsx
<Marquee>welcome to mostly_empty.com ░░░ last updated 06.23.2026</Marquee>
<Marquee rainbow={false} tone="paper" speed={28}>
  the pool was drained two summers ago
</Marquee>
```
