# OverexposedText

Pixel display text wrapped in a soft halo. The "JPEG that's been saved one too many times" look. Reserve for hero headers and section openers.

```jsx
<OverexposedText as="h1" size={120} color="paper" glow="peach">
  mostly empty
</OverexposedText>

<OverexposedText size={56} color="peach" glow="rose">about</OverexposedText>
```
