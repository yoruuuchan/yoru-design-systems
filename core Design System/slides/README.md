# Slides — sample templates

Six 1280×720 slide types, each a standalone `.html` file. Use them as starting points for a deck — copy, paste, edit copy/imagery.

| File | Use for |
|---|---|
| `TitleSlide.html` | Hero opener — overexposed display title + marquee + logo |
| `IndexSlide.html` | Table of contents / agenda |
| `SectionSlide.html` | Chapter divider — big numeral + section label on ink |
| `ImageSlide.html` | Full-bleed photo with a paper "ledger" overlay |
| `QuoteSlide.html` | Pull quote — oversized italic Tinos on a peach halo |
| `EndSlide.html` | Closing — pixel "fin." + marquee + web-ring nav |

All six are 1280×720. Backgrounds vary on purpose — paper / ink / tiled — so a deck has rhythm.

Each slide is standalone — assemble a deck by copying the files in order and editing in place; there is no runtime stage script.
