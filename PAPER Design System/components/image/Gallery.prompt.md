An even grid of photographs — portfolio pages, picture essays, index pages.

```jsx
<Gallery columns={3} ratio="4/5" items={[{src:"/1.jpg"},{src:"/2.jpg"},{src:"/3.jpg"}]} />
```

Gap stays tight (8px) so the grid reads as one object. Turn on `captions` only when every frame has something to say; otherwise caption the group once beneath it.
