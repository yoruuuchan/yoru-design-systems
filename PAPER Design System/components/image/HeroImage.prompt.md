Opens an article or a spread. In PAPER the image usually sits *after* the headline, not behind it.

```jsx
<HeroImage bleed ratio="16/7" src="/coast.jpg" number="Fig. 01"
  caption="Låtefossen at first light, 06:12." />
```

Only use `overlay` when the photograph has a genuinely empty quarter. Type over a busy image is not this system.
