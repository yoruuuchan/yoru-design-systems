The identity bar at the top of any PAPER page — wordmark, nav, rule.

```jsx
<Masthead title="PAPER" items={["Essays", "Portfolio", "Archive", "Colophon"]} active="Essays" />
```

Use `rule="double"` only on issue covers and section openers. Pass `right` to swap the nav for an issue line. Nav labels stay sentence case, never uppercase — the wordmark carries the caps.
