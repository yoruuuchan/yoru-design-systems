# Avatar

Initials, image, or icon. Chamfered square (default — KUNLUN's signature). Round shape for human-user contexts.

For live presence, pair with a separate `StatusPill` next to the avatar — KUNLUN doesn't ride a status dot on the avatar itself.

```jsx
<Avatar initials="LX" />
<Avatar src="/u/zhao.png" alt="赵" shape="round" size="lg" />
<Avatar size="sm">▣</Avatar>
```
